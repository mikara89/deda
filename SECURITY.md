# Security Policy

## Supported versions

Security fixes are provided for the latest released version. This project is
currently pre-1.0, so users should upgrade to the newest release before
reporting an issue.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **Report a vulnerability** form
on the repository's Security tab to submit a private security advisory. Include
the affected version, deployment configuration, impact, reproduction steps,
and any proposed mitigation.

You should receive an acknowledgement within five business days. We will keep
you informed while we validate and remediate the report, coordinate a release,
and publish an advisory. Please allow a reasonable remediation window before
public disclosure.
